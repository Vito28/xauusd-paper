Dokumentasi XAUUSD Market Data Collector¶

Dokumentasi ini menjelaskan collector MetaTrader 5, penyimpanan PostgreSQL, validasi data, analytics, serta dashboard FastAPI. Analytics bekerja pada salinan data melalui transaksi read-only; database tetap menjadi sumber data.

Untuk menjalankan dokumentasi ini sebagai website lokal, gunakan:

uv run mkdocs serve

Lalu buka http://127.0.0.1:8000/.

Analytics PNG¶

Analytics berisi dua file Python: data.py untuk query read-only dan persiapan data; analytics.py untuk UNI, BI, MULTI, grafik time series, model return dengan validasi waktu, evaluasi dan forecast. Kode memakai pemisah # %% seperti notebook. Lihat panduan analytics untuk metodologi, batas interpretasi dan referensi paper.

uv run python -B -m analytics.analytics univariate `
  --source-id <uuid> `
  --symbol XAUUSD `
  --timeframe M5 `
  --start 2026-01-01T00:00:00Z `
  --end 2026-02-01T00:00:00Z `
  --columns close tick_volume spread_price

PNG dibuat di reports/analytics/ dalam subfolder sesuai mode analisis. Folder ini hanya artifact visual dan bukan source data; semua input tetap dibaca dari PostgreSQL. Jalankan ulang command untuk mengganti PNG dengan hasil terbaru, atau tambahkan polling agar otomatis refresh:

uv run python -B -m analytics.analytics univariate `
  --source-id <uuid> `
  --symbol XAUUSD `
  --timeframe M5 `
  --start 2016-01-01T00:00:00Z `
  --end 2027-01-01T00:00:00Z `
  --watch-seconds 60 `
  --columns close tick_volume spread_price

Watcher melakukan query ulang setiap interval dan berhenti dengan Ctrl+C.

Forecast XGBoost 2026¶

Modul forecast memisahkan history tepat pada 2026-01-01T00:00:00Z. XGBoost hanya melihat close harian sampai 31 Desember 2025, lalu memprediksi 2026 secara recursive. Harga aktual 2026 dibaca terpisah sebagai ground truth visual dan evaluasi, bukan sebagai fitur, target training, atau state inference.

uv run python -B -m analytics.analytics forecast `
  --source-id <uuid> `
  --symbol XAUUSD `
  --timeframe M5 `
  --history-start 2016-01-01T00:00:00Z `
  --actual-end 2026-11-01T00:00:00Z

PNG, dashboard.html interaktif, dan metrics.json berisi MAE, MSE, RMSE, serta MAPE disimpan di reports/analytics/xgboost_forecast/. --actual-end adalah batas eksklusif data pembanding, bukan batas training.

Insight time series¶

Gunakan uv run python -B -m analytics.analytics time-series --source-id <uuid> --symbol XAUUSD --timeframe M5 --start 2016-01-01T00:00:00Z --end 2026-10-01T00:00:00Z --include-models. Laporan mencakup tren/drawdown, return/volatilitas, distribusi tahunan, return bulanan, ACF, aktivitas/spread, Spearman, counts dan perbandingan model UNI/BI/MULTI versus baseline. Tahun/bulan terakhir mengikuti cakupan observasi dan dapat parsial; harga meningkat jangka panjang belum berarti setiap sesi naik. Output berada di reports/analytics/time_series/.
