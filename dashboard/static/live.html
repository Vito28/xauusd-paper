Cara kerja halaman ini
  • Alur: MetaTrader 5 → LiveService (polling 1 detik) → FastAPI WebSocket /ws/live → browser. Tidak ada order yang dikirim ke broker.
  • Paket Python MetaTrader5 hanya berjalan di Windows dengan terminal MT5 yang sudah login. Di Linux/Docker status akan Tidak terhubung dan grafik memakai data historis PostgreSQL (diberi label jelas, bukan harga live).
  • Prediksi dibuat hanya ketika sebuah candle M5 selesai, memakai model dari runs/*/live_bundle.joblib (hasil final-test, dilatih dengan data ≤ 2025). Model tidak dilatih ulang di sini.
  • Status PENDING berarti horizon belum selesai; hasil aktual baru diisi (EVALUATED) setelah candle t+H tersedia, dengan definisi label triple-barrier yang sama seperti training.
  • NO_TRADE ditampilkan sebagai status, bukan sinyal transaksi.
