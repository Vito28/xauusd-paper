# Dokumen Proyek Technical Agent XAU/USD M5

Semua dokumen Kelompok Goldmind dikumpulkan di folder ini (branch `documents`).
Kode, konfigurasi, dan hasil run ada di branch `main`.

| File / folder | Isi |
|---|---|
| `LAPORAN UTS MILESTONE 1.docx` | Laporan UTS Milestone 1 |
| `BUSINESS UNDERSTANDING.docx` | Business understanding, aturan transaksi, dan perumusan matematis XGBoost. Juga dipakai sebagai template style laporan |
| `DOKUMENTASI KERANGKA SISTEM.docx` | Kerangka sistem dari sudut pandang developer: data, konfigurasi, strategi training, dan fungsi kode XGBoost |
| `Petunjuk.docx` | Petunjuk menjalankan proyek: sumber dataset, instalasi uv, PostgreSQL, perintah uv, dan ringkasan hasil |
| `laporan_uts/` | Sumber markdown laporan, skrip pembuat tabel dan gambar dari folder `runs/`, dan `md2docx.py` |
| `materi/` | PDF materi kuliah sebagai referensi |

## Membuat ulang laporan

Langkah lengkapnya ada di komentar baris awal `laporan_uts/laporan_uts.md`.
`LAPORAN UTS MILESTONE 1.docx` dibuat dari markdown tersebut, jadi suntingan yang
dilakukan langsung di Word perlu disalin dulu ke `laporan_uts.md` sebelum docx
dibuat ulang. Jika tidak, suntingan itu akan tertimpa.
